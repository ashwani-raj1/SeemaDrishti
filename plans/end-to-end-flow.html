Pixel to Audited Decision

Four processes, each able to run on a different laptop. A person walks past a camera and, if it mattered, a human decision about it ends up hash-chained in a log at the post — with nothing leaving the building.

The whole path, one picture

Lanes are processes. Follow the solid line down the middle; the two coloured lines are the channels that skip the queue and go straight to the screen.

Same thing in words

  1. A source publishes. A looping clip or a real camera — one RTSP push into the hub. Nothing downstream can tell which.
  2. The hub fans out. One process pulls each source once. Cheap IP cameras cap at 2–4 sessions, so everyone else reads from the hub, not the camera.
  3. The browser gets WHEP. Browsers cannot play RTSP — no flag, no polyfill. Something has to repackage it, and this is the only transport fast enough for a live security screen.
  4. A worker pulls RTSP and detects. YOLO11n + ByteTrack, person boxes with track ids. One worker per laptop; which cameras is IBVAP_WORKER_CAMERAS.
  5. Boxes go straight to the screen. WebSocket, ephemeral, never stored. If nobody is looking at the tile, a box is worthless.
  6. Detections go to the node. One POST to /hooks/ingress/detections — the only door a detection enters through, and the same one the simulator uses.
  7. The fence judges. Inbound and outbound are different events, and a crossing must hold for the zone’s confirm seconds before a critical alarm fires. A single frame’s flicker is rejected, not shouted.
  8. An event is written. Append-only, with a monotonic sequence number. Cattle are written down and never alerted on — that distinction is the whole false-alarm argument.
  9. Events group into an incident. Same camera, same zone, inside a bounded window. The operator’s unit of work is “someone crossed the fence”, not forty detections.
  10. SSE pushes it to the queue. Live, over the same HTTP port. No Redis, no queue service — nothing extra to power at a post that may not have mains electricity.
  11. The operator decides. Acknowledge, escalate or dismiss. Escalate and dismiss are refused without a written reason.
  12. The decision is the record. One hash-chained audit row: who, when, why. incident has no status column — its state is a SQL view over that log, so no code path can change it without leaving an attributed row behind.
The whole path is local. One SQLite file at the post holds everything, and no cloud service sits anywhere in the working path — a post with a dead uplink runs the complete feature set. Every address in the diagram comes from one .env, so moving a process to another machine is editing a line, not editing code.

What you actually run

Four terminals, in this order. Each box in the diagram is one of them.

# once
Copy-Item .env.example .env
python media/fetch.py --synthetic     # or point cameras.yml at real footage
python media/configure.py

# then, one per terminal
media/bin/mediamtx.exe media/mediamtx.yml   # 1 — the hub
bun run dev                                 # 2 — node :8000 + console :3000
python ibvap/service.py                     # 3 — detection
The synthetic clips are not a detection test. They prove hub → browser and hub → worker plumbing and will produce zero detections — YOLO will not find a person in a test pattern, and it should not. Real footage is required before any detection claim means anything.
